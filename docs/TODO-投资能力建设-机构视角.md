## 一、方法：专业机构的投资链条（14 环）

一家专业机构的能力不止"研究一家公司"，而是一条闭环流水线：

```
哲学治理 → 想法来源 → 尽调研究 → 估值建模 → 决策仓位 → 组合构建 → 风险管理
   → 执行交易 → 监控跟踪 → 复盘归因 → 宏观配置 → 数据基建 → 合规报告 → 知识管理
```

**AI Berkshire 的强项集中在"尽调研究"这一环（业内少见的深度），但作为机构，越往组合、风险、执行、归因、数据基建走，缺口越大。** 这正是"研究员"与"投资机构"的差距。

> **能力分两条正交的轴：**
> - **流程轴（把事做对、不出错）**——上面这条 14 环链条；
> - **Alpha 轴（比市场更早、更准地找到赢家）**——宏观判断、板块轮动、主题捕获，尤其是挖掘可能有 10 倍空间的高潜力标的。
>
> 两轴都有缺口，其中最大的 Alpha 缺口是：**现有 skill 分析的几乎全是大盘、已被券商充分覆盖的名字（腾讯/茅台/NVDA），项目没有任何"小盘/新兴赢家发现引擎"。** 详见第四节。

## 四、Alpha 轴缺口 TODO（真正决定超额收益的一轴）

> 流程轴是"把事做对"；这一轴是"**做对的事**"——产生超额收益的能力，也是当前最弱、最值得补的一环。

### A. 🚀🚀 高潜力/十倍股挖掘 —— 项目最大的 Alpha 空白 · 最高优先

- [ ] **`/multibagger-hunter` 十倍股猎手**（+ 配套小盘/冷门股数据）
  - **现状缺口**：现有所有 skill 都在分析**大盘、已被充分覆盖、市场已定价**的名字（腾讯/茅台/NVDA）——这些几乎不可能是下一个 10 倍股（大象难跳舞）。**项目完全没有"在共识之前发现赢家"的引擎。**
  - **十倍股 DNA（筛选维度）**：
    1. **小市值基数**——10 倍需要低起点（几十亿~几百亿，而非万亿）
    2. **长长的雪道**——大 TAM + 低渗透率 + 处于 S 曲线早期（技术采纳曲线的陡峭段前）
    3. **可复制的单位经济**——门店/SaaS/平台式、边际成本递减、跑道清晰
    4. **高速且可持续增长**——收入/利润复合 20–40%，且非一次性
    5. **戴维斯双击潜力**——盈利增长 × 估值提升 双轮（当前被低估 + 未来被重估）
    6. **卓越的资本配置者/创始人**——owner-operator、再投资跑道长（Nick Sleep "规模经济共享"）
    7. **隐藏的期权价值**——第二增长曲线/新业务（如早期亚马逊的 AWS、腾讯的微信）
    8. **被市场忽视或看错**——券商覆盖少、非共识、误解——**信息优势的来源**
    9. **结构性顺风**——踩在长期趋势上（AI、电动化、老龄化、创新药、机器人、消费升级）
    10. **赢家通吃的早期**——网络效应/规模效应尚未被市场看清时
  - **打法（关键）**：10 倍股极稀有、失败率极高——用**塔勒布杠铃 + 风投式组合**：一篮子**小仓位**押多个非对称候选，允许多数归零、靠少数 10 倍拉动整体。**不是集中重仓，而是分散的期权式下注。**
  - **⚠️ 诚实警示**：幸存者偏差极强（事后看都"显而易见"）、绝大多数"潜力股"会失败、须严格小仓位、须区分"高潜力"与"高估值故事股"。
  - **交付**：全市场（尤其中小盘/科创/北交所/港股新经济）扫描 DNA 标记 → 候选池 → 逐一用四大师 + 费雪(一手) + 林奇(成长分类) 深研 → 输出"风投式组合"仓位建议。
  - 影响：★★★★★（收益的真正来源）工作量：大（需数据基建 + 小盘覆盖）

## 七、一句话总结

> AI Berkshire 已经是一个**世界级的"研究员"**（尽调深度、四/十三大师异见庭、数据严谨性验证），
> 但它有两条大缺口：
>
> **流程轴**——要成为"投资机构"，还差三条腿：**能量化组合风险、能诚实复盘归因、有扎实数据基建**。
>
> **Alpha 轴**（更根本）——它目前只会"深研你已经知道的大公司"，**不会"在市场发现之前找到下一个十倍股"**。宏观、板块轮动、主题捕获、尤其是**小盘/新兴赢家的发现引擎**几乎全部缺失。
>
> **一句话：现在的它擅长"确认一家好公司值不值得买"，还不擅长"率先找到那家没人注意的好公司"。** 前者是"不亏钱"的能力，后者才是"赚大钱"的能力——而十倍股，只可能来自后者。
