# 信号与策略能力路线图（2026-07-17）

> 承接「全链路能力诊断评级」。目标：把散落的信号工具，建成 **"信号发现 → 有效性校准 → 组合成策略 → 严谨回测 → 组合落地 → 治理留痕"** 的可运转、**防过拟合**闭环。
>
> **方法**：4 角度路线图设计（严谨优先 / 边缘发现 / 基础设施 / 研究闭环）→ 防过拟合对抗审查 → 首席综合（6 agent）。**路线图只认代码实证的现状与断链，不画大饼。**

## 裁定（一句话）

**"先修 rigor 再测信号"方向对，但要前置真正 binding 的那种 rigor**——不是幸存者门禁（现有 31–38 只全在世的池子上是**空操作剧场**），而是三件真东西：① 无法回填的防挖掘地基（**密封 holdout + 试验台账**）；② 一条 **OOS-first 的产收益回测脊柱**（这是造引擎的真活，因为 `backtest_rigorous` 经代码核实只是审计器、没有产收益循环）；③ 替换 `signal_calibration` 朴素判定的**显著性栈**（bootstrap→经验 p→FDR）。

## 二、总主张：排序即防线

**四版路线图的共同盲区**：没人把"**样本能否支撑任何 OOS 结论**"排在造发现机器之前。所以第 0 件事是**功效体检**——38 PIT 标的 × ~6 年年报；单标的日线信号在重叠 20 日窗口下，把 21 次 RSI 触发压成 **≈3–5 个独立观测**。**诚实预期：样本大概率只支持极少数、甚至零个可验证 edge。**

排序按"**边际约束**"而非"叙事顺手"：先立无法回填的防挖掘地基 → 焊 OOS-first 产收益脊柱 → 上显著性栈与门禁 → 才扩面测信号 → 最后组合上线。**反序（先扩信号后补 OOS）= 数据窥探。**

## 三、分阶段路线图（P0–P3）

### P0 · 功效体检 + 两件无法回填的防挖掘地基 + 一条 OOS-first 产收益脊柱
**目标**：测任何信号前，先回答"样本撑不撑得起 OOS"，立起唯二无法事后回填的东西，并焊通一条端到端、OOS-first、扣成本的产收益回测循环。
**关键交付**：
- **功效备忘**（1 页）：算工作池的有效独立观测数，给出"样本大概率≈零个可验证 edge"的诚实锚。
- **密封时间轴 holdout**：冻结工作池最近 ~24 个月，切分规则写进版本控制文件、标"发现阶段永不触碰"，代码路径加断言不读 holdout 段。
- **`data/signal_trials.jsonl` append-only 试验台账**：`signal_calibration` 每次校准（从第 1 次起）追加 `{信号规格/universe/horizon/n/edge/切分/as_of/git_sha}`——多重比较的**分母**。
- **产收益脊柱**：给 `backtest_rigorous` 加 `run` 子命令（或新建 `strategy_backtest.py`）：`factor_library.gather_raw(as_of=d)`（已核实 PIT 安全）→ 标准化 → composite → `delisting.universe_as_of` 取当时在市池 → 组合 → 扣 TCA 净收益，**walk-forward OOS 写进第一个 commit**。
**依赖**：无（起点，复用现有 factor_library/delisting/tca）。
**退出标准**：① 功效备忘已给出有效 N；② holdout 切分冻结且有测试断言不读 holdout；③ `signal_trials.jsonl` 从第 1 次起记录；④ 脊柱端到端跑通一条单因子策略、头条是 OOS 净收益。

### P1 · 把"能跑"升级为"可信"：显著性栈 + 反转覆盖率门禁（先于任何广度）
**目标**：复制到第二个信号前，把描述性校准升级为受控 family-wise error 的推断，并堵死 V1 会造出的空操作门禁剧场。
**关键交付**：
- **替换 `signal_calibration.verdict()`**：`edge>0` 朴素判定 → **block-bootstrap 经验零分布（尊重重叠窗口自相关）→ 经验 p 值 → BH-FDR/Bonferroni 族内校正**（正是工具自认缺失的那道）。
- **deflated Sharpe / 试验计数 haircut** 落入 quant_metrics（或新建 overfit 工具）：试了 N 个就按 N 惩罚。
- **反转覆盖率门禁**：修正数据（退市/PIT/CA）对被测标的缺失时，**拒绝声称"无偏差"、强制标 `coverage-absent 不可信`**（现有退市库仅 4 条、无一在池 → 必须触发）。
- **预注册台账**：OOS 跑前先落 `{因子/参数/假设/horizon}`；元搜索超参（holdout 定义、bootstrap 块长）一并预注册。
**依赖**：P0（有脊柱 + 台账才有东西可校正）。
**退出标准**：① verdict 改为经验 p + FDR，旧逻辑删除有回归测试；② 任一结果都带试验计数与 deflated 指标；③ 覆盖率门禁上线并在现有 universe 上触发 coverage-absent。

### P2 · 广度：五面 + 因子逐一过 IS-FDR + 密封 OOS 双闸，清废件、补治理
**目标**：只有 P0/P1 就位后才扩面。五面（技术/资金/情绪/消息/板块）+ 更多因子逐一喂脊柱，过双闸；无 edge 明确退役。
**关键交付**：
- **信号适配器接口**：每个信号 = 纯函数 `bars→触发日索引`，PIT 安全；封装 technicals/moneyflow/sentiment/factor 的现有读数（`signal_calibration` import 之，闭断链 #3）。
- **晋级双闸**（独立）：进"信号有效性登记册"须**同时**过 (a) 样本内 FDR 校正后显著 **且** (b) 密封 holdout 同号且量级 material。
- **治理补齐**（闭 #5）：五面 5 工具 registry/code_gate/lineage 命中 0→全命中。
- **清废件**（闭 #4/#6）：`momentum_backtest_v2`（硬编码）、`stock_screener`（input()）标 deprecated 或重构为纯函数框架实例。
**依赖**：P1（显著性栈 + 门禁必须先于扩面，否则批量测=批量挖掘）。
**退出标准**：① 至少 2–3 个信号/因子跑完双闸并判定，登记册记录每个的试验总数；② 五面治理 0→全命中（ci --strict 可体检）；③ 废件 deprecated 且不可作活策略 import。

### P3 · OOS 幸存者组合化 + 上线纪律：接 L4 风险 / L5 运营 + paper-trading
**目标**：把少数经双闸的 OOS 幸存者组合成策略，接已达 L4 的风险闭环与 L5 运营回路，paper-trading 前瞻验证 + 上线漂移监控。
**关键交付**：
- 策略层接 `portfolio_risk`（IPS 越限门禁）/ optimizer / rebalance / tca（真实成本）——复用 L4。
- **paper-trading 真实前瞻**：`signal_calibration` 记录真实（非回填）前瞻收益，接 decision_journal / thesis_tracker。
- **上线漂移监控**：复用 cron + `monitor.check_runs`（dead-man's-switch）+ run_audit 可重放，实盘 vs 回测偏离即 `notify.py` 告警——复用 L5。
- **promote 门禁**：策略级 model_registry 登记 + CI --strict；OOS 未达标或实盘偏离不得 promote。
**依赖**：P2（只有经双闸的 OOS 幸存者才配接资金）。
**退出标准**：① 至少 1 个 paper-traded 策略在跑真实前瞻收益、与回测预期自动比对、偏离触发 notify；② 策略受 IPS 约束、扣 TCA 后仍为正。

## 进展（2026-07-17 已开工）

**P0/P1 防过拟合护栏已落地**（护栏先行）：新建 `signal_lab.py`（零依赖，25 golden 测试）——功效体检 `effective_independent_obs`、密封 holdout `holdout_split`/`assert_no_holdout_leak`、试验台账 `record_trial`/`trial_count`、`walk_forward_splits`(purge/embargo)、显著性 `block_bootstrap_pvalue`(尊重自相关)、`benjamini_hochberg`(BH-FDR)、`deflated_sharpe_pvalue`(Šidák 试验惩罚)、反转覆盖率门禁 `coverage_verdict`。已登记 model_registry(42)、纳 CI。
**已接入 `signal_calibration`**：每次校准自动算有效独立观测 + block-bootstrap 显著性 + 写试验台账（`data/signal_trials.jsonl`，gitignore）。实测 AAPL RSI 超卖：朴素"有效"(+2.01%) 被 signal_lab 降级——**有效观测仅 15、自助 p=0.077 不显著**（当场拦下假阳性）。
**仍待（P0 大件）**：OOS-first 产收益脊柱（`backtest_rigorous` 加 `run`：factor_library PIT-safe → 组合 → 扣 TCA → walk-forward OOS）；随后 P1 用 signal_lab 替换 `verdict()`、P2 扩面。

3. **建 `data/signal_trials.jsonl` append-only 台账**：改造 `signal_calibration` 让每次（从第 1 次起）校准追加试验记录（多重比较的分母）。
4. **给 `backtest_rigorous` 加 `run` 子命令**（或新建 `strategy_backtest.py`）：只用已核实 PIT 安全的 ROE 质量因子 → 组合 → 扣 TCA 净收益，**walk-forward OOS 写进第一个 commit**，保持最小（纯多头、月度再平衡、单因子）。
5. **反转覆盖率门禁做成断言**：退市库仅 4 条、无一在池 → 工作池上的幸存者检查必须输出 `coverage-absent 不可信` 而非"无偏差"，从第一天防 V1 式空操作剧场。

## 五、防过拟合护栏（一等公民，贯穿全程）

1. **密封 holdout + append-only 试验台账**是第 1 步且无法回填——分母不从第 1 次记就永远重建不出、holdout 被挖过就洗不干净。
2. **OOS-first 焊死于第一个 commit**：walk-forward 内建、全样本夏普永不作头条（事后无法补装）。
3. **替换朴素 verdict**：block-bootstrap 经验零分布（尊重重叠窗口自相关）→ 经验 p → BH-FDR/Bonferroni——否则它是把噪声洗成"已验证 edge"的机器。
4. **deflated Sharpe / 试验计数 haircut 置于扩面之前**（试 N 个按 N 惩罚，防"试到显著为止"）。
5. **反转覆盖率门禁**：修正数据缺失时拒绝声称"无偏差"、强制标 coverage-absent（专治空操作剧场）。
6. **扣 TCA 净额为唯一头条**：很多样本内 alpha 扣成本后消失（防"忽略成本的过拟合"与"其实是 beta"）。
7. **数值对拍 oracle** 诚实定位为 **bug-check**（非防过拟合）：隔离 CI job 用 numpy/scipy 逐值对拍主库纯 Decimal，剔除"实现 bug 伪装成 alpha"；主库保持 zero-dep。
8. **预注册**假设/参数/horizon + 元搜索超参；**信号相关性去重**（剔"同一 edge 的多种伪装"）。
9. **paper-trading 真实前瞻**为最终、最贵、无法被样本内污染的检验。
10. **制度性接受"证伪也是成果"**：诚实预期≈零个幸存者；顶住"为免交白卷而放松门禁"的压力，治理剧场不得复发。

## 六、成功指标

- 每份回测都声明 survivorship/PIT/CA 覆盖率；缺失标 `coverage-absent` 而非"无偏差"。
- 100% 信号/策略结果报告 IS-vs-OOS 切分、试验计数、扣 TCA 净额——库内无"仅全样本"或"仅毛口径"的头条。
- `signal_trials.jsonl` 试验条数 == 历史校准次数（分母可审计、无隐藏失败）。
- 数值对拍：CAGR/vol/maxDD/协方差在隔离 CI 与 numpy/scipy 容差内一致；主库仍零 numpy/scipy。
- 五面 5 工具 registry/code_gate/lineage 命中 0→全命中（ci --strict 可体检）。
- 一个信号进登记册当且仅当**同时**过 IS-FDR 显著 + 密封 holdout 同号 material 两道独立闸。
- 废件 momentum_backtest_v2 / stock_screener 标 deprecated 且不可作活策略 import。
- P3：≥1 个 paper-traded 策略跑真实前瞻收益、与回测自动比对、偏离触发 notify。
- **最诚实的成功可能是登记册幸存者极少甚至为零——"证伪"作为合格交付记录，而非放松门禁。**

## 七、诚实边界

- **zero-dep 既是卖点也是约束**：主库无 scipy，显著性数学要么手写纯 Python bootstrap、要么隔离到 CI oracle；需长期维护两套实现同步（漂移风险）。
- **样本太薄**：38 PIT 标的 × ~6 年（13 只 A 股），重叠窗口把 21 次触发压成 ~3–5 独立观测 → **诚实预期是"≈零个可验证 edge"**。这套框架是为统计确认"样本本就可能不支持的结论"而造的精密机器，最可能结果是 null。
- **退市库仅 4 条**（LEHMQ/ENRNQ/WCOEQ/乐视），无一在工作池 → 幸存者修正在现有 universe 上基本空操作；门禁价值是诚实标注而非真去偏，真正 binding 需更广退市库。
- **A 股成长因子刻意不做**（免费无前瞻一致预期源→前视污染）；A 股当"覆盖"不当"证据"，不跨市场拼横截面。
- **24 个月 holdout 很可能单一 regime**：OOS 确认是必要非充分，检测不出 regime 依赖衰减。
- **TCA 冲击是线性桩、免费日线无盘中**：实盘 vs 回测差距难量化，必须以净额为闸。
- **加产收益循环是造引擎的真活**（backtest_rigorous 现为纯审计器），有范围蔓延风险——P0 须保持最小（纯多头、月度、单因子），否则催生仓促引擎、bug 伪装成 alpha。
- **组织风险**：一个被设计来"产出已验证信号"的系统会有"放松门禁以免交白卷"的压力——必须把"证伪也是成果"制度化。

## 附录·4 版设计角度与关键排序纠正

| 角度 | 主张 | 采纳 |
|---|---|---|
| 严谨优先(V1) | 先让 backtest 走 rigorous + 门禁 | 覆盖率门禁 idea 采纳，但**反转**（卡"修正数据覆盖率"防空操作剧场）；rigor 门禁在全在世池上是空操作，不作 first move |
| 边缘发现(V2) | signal_calibration 规模化 + 台账/holdout/FDR | **最深洞察采纳**：密封 holdout + 试验台账（唯二无法回填）+ block-bootstrap→BH-FDR |
| 基础设施(V3) | 先建统一策略框架 + 登记册 | 部分采纳；但**拒绝**其"框架先于证据""去膨胀排在填策略之后"的排序 |
| 研究闭环(V4) | 端到端焊一条 OOS-first 因子策略 | **first_move 采纳**：backtest_rigorous 加 run、OOS 写进第一个 commit；deflated Sharpe 置于扩面之前 |

**审查揪出的头号排序错误**：先修"在全在世池上是空操作"的幸存者 rigor（V1/V3），却把真正 binding 的 OOS/多重检验推后 → 造出"在缺失数据上通过"的门禁剧场。**纠正：功效体检 + 防挖掘地基 + OOS-first 脊柱同为 P0，显著性栈 P1 先于任何扩面。**
