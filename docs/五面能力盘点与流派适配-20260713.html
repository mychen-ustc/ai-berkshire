强依赖 中依赖 弱依赖 · "适配"＝本系统覆盖该流派所需各面的综合程度。
矩阵读法：
  • 价值/深度价值只重基本面 → 本系统强适配（这是设计初衷）。
  • 成长/事件驱动额外吃消息面(催化剂)与情绪面(认知差) → 当前中，补消息面后可升强。
  • 量化因子需要因子模型 + 统一回测 + 技术/资金信号 → 弱，最大缺口是因子模型。
  • 宏观对冲需要 regime + 跨资产 + 消息面 → 中（已补宏观 regime 引擎；跨资产 SAA/TAA 待建）。
  • 结论：补"消息面 + 情绪面 + 因子模型"三块，能一次性把成长/事件/量化/宏观四个流派从"弱/中"抬到"中/强"。
