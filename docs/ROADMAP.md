# ai-berkshire Roadmap

## P0：近期（1-2个月）

### A股数据源接入
- 接入 akshare、东方财富等免费数据源
- 覆盖 A 股财务数据、行情、龙虎榜
- 现有 Skill 无需改动，数据层扩展即可

## P1：中期（3-6个月）

### HTML 报告输出
- 在 Markdown 基础上增加 HTML 报告格式
- 支持暗色模式、导航栏、图表可视化
- 提升报告传播性和阅读体验

### 多档深度模式
- `lite`：5分钟速判，快速给出估值区间和核心结论
- `standard`：当前默认模式，完整多Agent研究
- `deep`：增加更多交叉验证和历史类比，机构级深度

### 多股横向对比
- 支持 2-4 只股票同维度横向对决
- 同行业公司估值对标
- 输出对比矩阵和择优建议

## P2：长期（6个月+）

### 测试覆盖
- 为核心工具（financial_rigor.py 等）增加单元测试
- 为 Skill 输出增加回归测试
- 确保迭代不破坏已有功能

### 组合级分析
- 持仓组合健康度评估
- 行业/地域集中度分析
- 相关性风险检测

## 机构级能力建设路线图 —— 工具建设章 **基本完成**（2026-07-16）

自 2026-07 起的机构级能力建设（数据地基 → 因子/风险 → 组合/回测 → 治理 → 运营/编排 → 多市场流水线）
在**工具与能力覆盖**层面已**基本完成**：**67 工具 · 435 回归测试全绿 · 32 登记模型 · 73 skill**（全零依赖）。
最后一批四方向（运营监控 / 代码质量门禁 / 因子风险分解 / T1 线索分诊）已全部落地。

但**"覆盖完成"≠"运营化完成"≠"数据充实完成"**。对全链路 12 域做了一次**经对抗验证的诊断评级**
（12 域并行审计 → 质疑防虚高 → 综合），加权 **3.3/5**，结论：**引擎级 L3+、双域 L4（风险/运营）、零域 L5**。

**下一章的题目不再是"造工具"，而是三件事**：
1. **数据充实**（P0）：为真实工作 universe 补齐退市/公司行动/证券主数据并自动摄取——当前反偏差引擎对空池空转。
2. **治理坐实**（P0）：治理修到旗舰（登记 dcf/industry_valuation/morningstar）+ 消除门禁盲区（已修 tests_missing stat）。
3. **运营化**（P1）：CI 刚性（`.github/workflows` 每 PR 跑测试+门禁）→ 无人值守自主运转 + 可重放审计（迈向 L5）。

详见 [全链路能力诊断评级-20260716](全链路能力诊断评级-20260716.md)（含 12 域 L0–L5 评级表 · [HTML 看板](全链路能力诊断评级-20260716.html)）。
