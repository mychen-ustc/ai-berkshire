Maturity standard

存在，不等于成熟。

一个 skill 或一份报告只能证明能力“出现过”。机构化要求结构化、自动化、异常处理和历史重放。

L0没有明确流程或资产
L1原则、模板或人工流程
L2skill / 工具可重复运行
L3结构化输入输出与交叉验证
L4自动化、测试、监控和版本齐全
L5可完整重放并经独立审计

P0

先补机构底座

任何一次决策都能记录、复现、监控和复盘

⌄

P0-1投资授权与 IPS

定义投资范围、总回报基准、风险预算、仓位/集中度上限、流动性、禁投、杠杆权限、审批和复审频率。

影响 ★★★★★工作量 小–中无前置依赖
完成定义所有风险、仓位与卖出建议引用同一套机器可读约束，不再硬编码通用阈值。

P0-2标的主数据与组合主账

建立 security master、交易/现金账本、公司行动、FX、费用税费与每日持仓净值的唯一事实源。

影响 ★★★★★工作量 大依赖 P0-1
完成定义任意历史日期可重建持仓、现金和净值，差异可定位到具体交易或公司行动。

P0-3统一数据层 v1

统一 A/H/美股行情、总回报、财报、估值、FX、基准和公司行动；保留 as_of、available_at、来源和版本。

影响 ★★★★★工作量 大依赖 P0-2 模型
完成定义同一快照可复现相同输出；缺失、过期和冲突数据不会被静默使用。

P0-4测试与模型治理

为工具建立单元/边界/golden tests；为 skill 建输出回归；登记模型版本、用途、限制、审批、异常与回滚。

影响 ★★★★★工作量 中与数据并行
完成定义修复伪精确运算；升级能自动识别破坏性变化，关键建议显示版本、假设和人审状态。

P0-5风险与业绩计算 MVP

组合波动、回撤、beta、HHI、行业/地域/货币暴露、相关性、压力情景，以及 TWR/MWR、基准超额和多币种收益。

影响 ★★★★★工作量 中–大依赖 P0-1/2/3
完成定义与人工样例及第二实现交叉验证；VaR 不替代回撤、流动性、集中度和尾部情景。
P1

跑通投资闭环

研究—决策—组合—监控—复盘形成学习系统

⌄

P1-1结构化决策日志

记录论文版本、价格、估值、情景概率、证伪条件、仓位、替代机会、审批和复审日期。

完成定义历史时点只展示当时已知信息，后续结果不得回填改写原始判断。

P1-2估值模型框架

多阶段/反向 DCF、WACC 敏感性、SOTP、重复加计检查和金融/资源/SaaS/消费等行业模板。

完成定义假设有来源与版本；终值占比过高自动警示；至少与一种独立方法交叉验证。

P1-3完整风险与压力测试

补充因子、风格、流动性、容量、拥挤、杠杆和交易对手暴露，支持历史、假设和反向压力测试。

完成定义风险限额来自 IPS；越限自动生成解释、降级或审批记录。

P1-4业绩归因与决策校准

按适用场景采用 Brinson、因子或交易级归因；拆分配置、选股、择时、汇率、费用和交互影响。

工作量 大依赖交易账本
完成定义统计 Brier score、估值区间覆盖率和红线命中率，形成可检索错误模式库。

P1-5统一 Watchlist 与监控

合并多套 watchlist/召回池，建立发现→初筛→深研→候选→持有→退出状态机和催化剂日历。

完成定义每个标的有负责人、论文版本、红线和复审日；告警支持去重、重试和过期提示。

P1-6仓位与卖出纪律

分数凯利只作参考，叠加 IPS、流动性、相关性、风险预算和概率区间；卖出覆盖论文、估值、机会成本和税务。

完成定义禁止仅凭单一评分或“高赔率”直接产生固定仓位。

P1-7会计异常与治理筛查

覆盖应收、存货、现金流背离、资本化、关联交易、商誉、审计意见、股权质押、AB 股和薪酬对齐。

完成定义Benford/Beneish 只作为异常线索，不得输出“证明造假”。
P2

扩展 Alpha 实验室

在稳定底座上验证策略，而不是事后寻找成功故事

⌄

P2-1新兴赢家发现引擎

用 TAM、渗透率、单位经济、资本效率、管理层、壁垒、期权价值和失败可承受估值筛选候选。

验证要求采用点时股票池、退市与失败样本；报告假阳性、回撤、容量和样本外表现。

P2-2多因子系统筛选

价值、质量、成长、动量、低波、规模和盈利修正；纳入行业中性、退市收益、换手、滑点和税费。

验证要求训练、验证和样本外严格分离；用于缩小研究范围，不自动下单。

P2-3宏观 Regime 与配置

增长、通胀、流动性、信用、利率、汇率和政策周期，连接目标配置区间、再平衡和风险预算。

策略约束明确宏观判断影响哪些决策，避免随意污染自下而上估值。

P2-4行业景气与主题

订单、价格、产能、库存、盈利修正、资金流、相对强弱，以及主题受益纯度、拥挤度和退出条件。

完成定义与行业研究/漏斗共享分类和候选主数据，避免多套口径。

P2-5事件驱动与特殊机会

并购、分拆、私有化、要约、回购、重组、指数调整和融资事件分别建模概率、时间价值和法律条件。

风险原则不把整个类别概括为“确定性较高”；必须建失败与融资情景。

P2-6一手验证与信息 Edge

scuttlebutt、渠道验证、专家访谈和另类数据；区分可验证事实、受访者观点与研究员推断。

前置条件先通过 MNPI、保密、隐私、利益冲突和数据授权检查。

P2-7分市场与另类资产模块

A 股制度/可转债、港股流动性/配售、美股做空/期权；一级、REITs、债券、商品和加密另建 mandate。

风险原则“下有保底”“小盘易十倍”只能是待验证假设，不能作为产品承诺。
P3

真实资管运营第三方资金触发

一旦管理客户资产，本阶段立即升级为 P0

⌄

P3-1OMS / EMS

订单、审批、分配、撤单、成交和异常状态的完整生命周期。

P3-2交易合规

预交易/交易后禁投、集中度、关联交易、最佳执行和个人交易。

P3-3经纪与交易对手

经纪商、托管人、保证金、借券、授信与交易对手风险。

P3-4清算与对账

现金、公司行动、交收、持仓和交易的日常对账与异常处置。

P3-5基金会计与 NAV

估值政策、费用计提、价格挑战、NAV 计算和错误更正。

P3-6流动性与申赎

容量、申赎、压力下变现计划、闸门和流动性分层。

P3-7客户与监管报告

客户报告、监管报送、绩效展示、费用披露和错误更正政策。

P3-8安全与业务连续性

权限、密钥、网络安全、灾备、业务连续性和供应商风险。

P3-9利益冲突与 MNPI

利益冲突、礼品招待、专家网络、重大非公开信息和举报机制。

优先级纠偏

从“快做一个工具”转向“建立可用能力”

先做凯利仓位工具→先定义 IPS 与组合风险预算
数据基建排在 Alpha 后→主数据、账本和点时数据前置 P0
合规 / IPS 为低影响→升级为横向 P0 控制线
十倍股是最高核心 Alpha→改为有风险预算的卫星策略
卖出纪律属于 Alpha→并入决策、风险与机会成本闭环
执行 / TCA 工作量小→个人模式简化；资管模式为大型工程

排序原则

避免被“看起来有产出”的项目带偏

先规则，后算法没有 mandate，仓位和风险建议就没有约束依据。
先事实源，后归因没有交易、现金和公司行动，业绩拆解不可复现。
先闭环，后扩张不能监控和复盘时，更多策略只会增加不可控复杂度。
先风险预算，后故事新兴赢家和特殊机会必须作为有限预算的策略模块。
