# 全链路能力诊断评级（2026-07-16）

> 承接 `能力建设进度与下一批方向-20260715.md`。路线图四方向（监控/代码门禁/因子风险/线索分诊）已全部落地，工具/能力覆盖层面**基本完成**。本文对**全链路 12 个能力域**做一次**经对抗验证的诊断评级**（12 域并行审计 → 逐域对抗质疑防虚高 → 首席评估官综合），明确后续改进方向。
>
> **方法**：每域一名审计员读代码+跑测试给 L0–L5 评级 → 一名对抗质疑员专找"自评虚高"证据复核 → 综合。25 个 agent、385 次工具调用、17 分钟。**评级只认代码与测试实证，不认文档自述。**

## 一句话结论

**加权约 3.3 / 5**——系统处于 **"引擎级 L3+、双域 L4、零域 L5"** 的成熟度：

> 工程内核扎实（全程 Decimal 精度、纯函数、**460 测试 0.11s 全绿**、诚实边界遍布每个文件），但作为"事实源"的**数据底座近乎空置**、**治理只覆盖到脚手架而未管到旗舰且已出现漂移**、**全 12 域无一具备可验证的自动运转**。
>
> 本质：**一套"算得准、但没在自动转、且喂进去的是玩具级数据"的高质量单机研究工具箱**，而非在运营的机构级平台。

这不是唱衰。工具覆盖确已"基本完成"——但"覆盖完成"≠"运营化完成"≠"数据充实完成"。诊断的价值正在于把后两个缺口从文档的乐观叙事里揪出来。

## L0–L5 评级标尺

| 级 | 含义 |
|---|---|
| L0 | 无 |
| L1 | 脚本/玩具（硬编码、print 叙事、零测试） |
| L2 | 结构化工具 + 基本单测 |
| L3 | 干净工具 + 单测 + **交叉验证**（多源/多模型互印证） |
| L4 | L3 + **治理**（登记/门禁/血缘）+ 可复用 + 有数据（**手工补录的引擎天花板即 L4**） |
| L5 | L4 + **自动运转 + 漂移监控 + 可重放审计**（机构级平台） |

## 三大结构性短板（全链路共性）

### ① 事实源近乎空置 —— 全系统地基裂缝
delisting.jsonl 仅 1 行、corporate_actions.jsonl 仅 1 行、security_master.json 与 pit_store.json **磁盘上根本不存在**（已 find 确认），实际工作 universe 是 24 只 A 股而幸存者/公司行动引擎的 A 股记录=0、PIT 仅美股 25 只。**两个招牌反偏差引擎对本该服务的池子纯空转**——引擎再精，喂进去的是玩具级数据。这是唯一同时卡住"数据层/回测/因子"三域的地基缺口。

### ② 治理"脚手架不管旗舰"且有漂移/剧场
治理是本系统的**差异化卖点**，但当前：旗舰绝对估值 dcf/industry_valuation/morningstar **零登记**；`statement_model`/`scenario` 登记引用的测试文件**磁盘上不存在却标 validated**，而 `audit_findings()` 只判 tests 字段非空、从不 stat 文件——对"已验证但测试不存在"**结构性失明**；asset_allocation 声明的数据血缘与代码矛盾。治理最该杜绝的正是"声明≠实现"，而它自己犯了。
**→ 已改善**：门禁盲区已修（`tests_missing` stat 校验）；3 旗舰已登记（morningstar 补测后 validated）；剩 asset_allocation/factor_library 漂移校正待办。

### ③ 全域零 L5 —— 没有一处被证明能自主运转
无 `.github/workflows`（PR 不自动跑测试/门禁）、无 pre-commit、cron 装了 3 条 review 但 **monitor.py（dead-man's-switch）不在 crontab**、日志证据显示定时任务**从未自主执行过一次**。"装了不转"比"没装"更危险——它给人"在运营"的错觉。
**→ 已改善**：`install-ingest-cron.sh` 已装周摄取 + 日 monitor 体检（monitor 现在 crontab 内、无人值守运行）；剩 `.github/workflows` PR-CI + 结果通知未做，故仍未达完整 L5。

## 最终裁定

> 系统处在**"引擎已具机构级骨架的高质量单机研究工具箱"**阶段——算得准、测试全绿、诚实克制，但**事实源空置、治理未管到旗舰、全域未被证明自主运转**。
>
> 离顶级机构级还差**三件事**：① 一个真实且自动摄取的点时数据底座；② 一个真正管到旗舰并能自查漂移的治理门禁；③ 一套被证明能无人值守自主运转且可重放审计的自动化回路。
>
> 当前的本质是**"能算、但没在转，且喂进去的是玩具级数据"**。路线图的"工具建设"章已基本翻篇，下一章的题目是**"数据充实 + 治理坐实 + 运营化"**——这三件事做完，3.3 才能真正走向 4.5+。
