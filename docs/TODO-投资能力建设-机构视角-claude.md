# TODO：投资能力建设路线图（专业机构视角 · Claude 版）

> 目的：把 AI Berkshire 从"个人研究工具箱"升级为一套**可复现、可审计、可持续改进的机构级投资决策系统**，并明确朝"顶级机构投研工具库"还差哪些能力。
> 初版：2026-07-10　｜　本次重大更新：2026-07-13（补记 P0–P2 已落地部分、重估成熟度、系统盘点空缺、新增 P3 制度化与 P4 顶级能力补全）
> 一句话原则：下一阶段的关键不是"能分析更多东西"，而是让每一个数据、判断、仓位、结果都能回答——**依据是什么、当时知道什么、承担多少风险、最终哪里对了/错了。**

## 零、读这份文档的三条前提

1. **能力 ≠ 有一个 skill。** 出过一份报告不等于有稳定数据管线；跑得通一次不等于可复现、可监控、可审计。用成熟度 L0–L5 度量（第三节），不用"强/弱"。
2. **底座普适，Alpha 是选择。** 组合账本、风险、归因、合规是任何机构的"底座"；十倍股、宏观轮动、特殊机会是"策略选择"，取决于投资授权，不是人人必备的核心。
3. **先能不亏钱地运转，再谈赚大钱。** 没有事实源和风险闭环，任何 Alpha 都无法被信任、被评价、被复用。

## 一、第一步永远是定义投资授权（Mandate / IPS）

**写任何工具之前，先确认"这套系统为什么样的投资服务"。** "价值型资管"和"对冲基金"不是同一种 operating model——杠杆、做空、衍生品、流动性、换手率、合规要求完全不同，会直接改变能力优先级。

### 1.1 默认工作假设（可改，但必须先写下来）

| 项目 | 默认口径 | 待确认 |
|---|---|---|
| 投资风格 | 基本面驱动、长期、价值偏成长、长仓为主 | 是否允许量化择时/主题轮动 |
| 投资范围 | A 股、港股、美股上市权益 | 是否含一级市场、债、商品、加密 |
| 投资期限 | 3–5 年为主 | 是否保留短期事件驱动 |
| 基准 | 按市场指定**可投资的总回报**基准（非价格指数） | 单一还是混合基准 |
| 组合目标 | 长期复合回报 + 控制永久损失 | 最大可接受回撤、现金区间、集中度上限 |
| 杠杆/做空 | 默认不用 | 若启用需新增保证金/借券/流动性/对手方能力 |
| 服务对象 | 首期为自有资金的投研与决策支持系统 | 若管第三方资金，立即前置 P5 运营与属地合规 |
| 最终决策 | AI 给证据/情景/建议，**人类审批** | 哪些动作需二次复核或投委会批准 |

### 1.2 两种目标状态，分开管理

- **目标 A（当前重点）：机构级投资决策系统**——从机会发现到复盘形成闭环，数据有时点/来源/版本，结论可复现，关键决策有人审有留痕。
- **目标 B（条件性）：真实资管 operating system**——面向第三方资金，增加 OMS/托管/NAV/清算/监管报告。**目标 A 没跑通前不投入 B；一旦管客户钱，B 的合规运营立即升为 P0。**

## 二、能力地图：一条主流程 + 五条控制线

机构投资不是 14 个串行环节，而是**一条主流程**外加**贯穿始终的横向控制线**——风险、数据、合规不是"研究完再加"的步骤。

**主流程：**
```
投资授权 → 机会发现 → 研究与预测 → 估值与决策 → 组合构建
        → 交易执行 → 持续监控 → 业绩归因与决策复盘 → 规则迭代
```

**控制线（贯穿全程）：** 数据治理 ｜ 风险管理 ｜ 合规与信息边界 ｜ 模型治理与测试 ｜ 审计留痕与知识管理 ｜ **AI 治理**（本系统特有，见第八节）

### 底座 vs Alpha

| 类别 | 解决什么 | 典型能力 |
|---|---|---|
| **机构底座**（普适） | 能否稳定、正确、可追责地管理投资决策 | IPS、账本、数据、估值、风险、归因、合规、测试、监控 |
| **Alpha 模块**（策略选择） | 在既定授权内靠什么获取超额收益 | 行业漏斗、新兴赢家、因子、宏观、事件驱动、渠道验证 |

## 三、成熟度盘点（L0–L5，2026-07-13 重评）

| 等级 | 定义 |
|---|---|
| L0 | 不存在 |
| L1 | 人工/文档化（有原则/模板/零散报告，靠人工执行） |
| L2 | 可重复（有 skill/工具，可按相似步骤重复运行） |
| L3 | 结构化（明确输入输出、结构化数据、交叉验证、有测试） |
| L4 | 生产化（自动化、监控、异常处理、权限、版本、调度） |
| L5 | 可审计（可完整重放历史结果，经独立验证/审计） |

> **重评说明**：2026-07-10 初版多数域评为 L1–L2。此后 P0–P2 大量落地（见第四节现状快照），故本次上调多个域至 **L3（有结构化工具 + 单元/golden 测试 + 交叉验证）**。但**几乎无一到 L4**——尚缺自动化调度、监控、模型登记、权限、可重放审计。诚实结论：**底座工具已成形（L3），但还不是"运转的机构"（L4）。**

### 对现状的准确表述（不吹不贬）

- **已从"结构化研究工作流"跨越到"有底座工具链"**：ledger/datalayer/portfolio_risk/performance/attribution/dcf/position_sizing/forensic/technicals/moneyflow 都是**可运行、带测试、可交叉验证的工具（L3）**，130 项 golden/单元测试全绿。这比初版（多为 L1–L2）是实质跃迁。
- **但离 L4/L5 还有明确距离**：几乎所有工具都是"手动调用、单次运行"，尚无**自动调度、持续监控、模型登记、权限、可重放审计**。工具在仓库里，还不是一台"自己会跑的机器"。
- **且顶级机构的若干核心能力域仍完全缺失**：多因子风险模型、一致预期跟踪、三表联动预测、可比公司估值、约束优化、尾部/流动性风险、持股/内部人跟踪、宏观 regime 引擎（见第七节 P4）。

> Alpha 模块必须明确策略假设、适用市场、风险预算、退出条件，并通过**点时、样本外、含成本**验证，不能靠事后案例证明有效。

- **P2-1 新兴赢家发现**　✅ `multibagger-hunter`：用"新兴赢家"替代"十倍股猎手"（DNA 清单 + 塔勒布杠铃小仓卫星，KPI 是提高组合期望，不是"找到几只十倍股"）。
- **P2-2 多因子与系统化筛选**　🟡 `stock_screener.py`/`momentum_backtest` 原型；⬜ 完整因子库（中性化/相关性/点时/退市/成本）见 P4-1。
- **P2-3 宏观 regime 与配置**　🟡 macro-analyst 专题；⬜ regime 工具与 SAA/TAA 见 P4-9/10。
- **P2-4 行业景气/轮动/主题**　✅ `sector_rotation.py` + industry-research/funnel。
- **P2-5 事件驱动与特殊机会**　✅ `special_situations.py`（并购/分拆/回购/指数调整，逐类建模概率与下行）。
- **P2-6 一手验证与信息 Edge**　✅ `scuttlebutt`（区分可验证事实/受访者观点/研究员推断，先过 MNPI 检查）。
- **P2-7 分市场与另类资产**　🟡 A/H/美制度差异散见于各 skill；⬜ 老千股防雷、13F、可转债等专项见 P4-8/16。

## 八、🆕 P3 —— 制度化与生产化（把已建的 L3 工具链升到 L4/L5）

> **工具已经有了，但还不是"运转的机构"。** P3 不是加新工具，而是把散落的工具包成一台**自己会跑、可监控、可追溯、可重放**的机器。这是当前**性价比最高**的一步——已投入的能力只有制度化后才真正可信赖、可复用。

### P3-1 统一事实源持久化（security master + 点时财务库 + 公司行动引擎）　影响★★★★★
- **security master**：内部唯一 ID ↔ 各市场代码/交易所/币种/GICS 行业/上市退市日；解决"同一公司多代码"和跨市场对齐。
- **point-in-time 财务库**：历史财报带 `available_at`（首次披露时点），回测/归因不得用当时未公布的数据（防前视偏差）。
- **公司行动引擎**：拆股/分红/配股/并购/指数调整的自动调整，统一复权口径。
- **完成定义**：任意历史日期可重建当日持仓/净值/暴露；所有工具只读这一个事实源。

### P3-2 模型登记册 + 数据血缘 + 复现日志　影响★★★★☆
- 每个工具/skill 登记：版本、用途、输入契约、限制、审批人、最近验证日；skill 变更纳入回归。
- 数据血缘：任一结论 → 来源 → 转换 → 模型版本 → 决策人可追溯。
- **完成定义**：报告标注生成时的 skill/工具版本与数据快照；升级能识别是否破坏历史样例。

### P3-3 调度与运营节奏自动化（机构的心跳）　影响★★★★☆
- 把第九节的每日/每周/财报季/每季/每年节奏做成**调度任务**，而非一次性手动动作。
- 告警引擎：去重/优先级/静默期/重试/数据过期拦截，避免告警疲劳。

### P3-4 统一 Watchlist 状态机　影响★★★★☆
- 合并 watchlist.json/瓶颈 watchlist/召回池/持仓为一个入口；状态：发现→初筛→深研→候选→持有→退出→归档。
- 每标的：负责人/论文版本/下一催化剂/红线/复审日。

### P3-5 事件/催化剂日历　影响★★★☆☆
- 财报/分红/解禁/回购/监管/论文 KPI 日历，驱动监控与复盘节奏；与 special_situations 共享事件源。

### P3-6 统一回测框架（点时 + 幸存者 + 成本 + 退市样本）　影响★★★★☆
- 把 momentum_backtest 原型升级为通用回测引擎：point-in-time 股票池、纳入退市/失败样本、含滑点/税费、训练/验证/样本外严格分离。
- **所有 Alpha 策略（P4-1 因子、P2 轮动/事件）都跑这一个引擎**，口径一致才可比。

### P3-7 错误模式库 + 决策校准闭环　影响★★★★☆
- 把 decision_journal + attribution 的 Brier/区间覆盖/红线命中沉淀为**可检索错误模式库**（不是错题集）；季度复盘淘汰无效规则。

### P3-8 AI 治理硬门禁（report_audit 升级）　影响★★★★★
- 断网即拒绝出结论（硬门禁）；来源可点击可核；版本/数据截止日强制标注；每份报告幻觉抽检。见第八·治理节。

## 九、🆕 P4 —— 顶级机构能力补全（当前完全缺失的能力域）

> 这些是顶级机构（自下而上如 Capital/Baillie Gifford，系统化如 AQR/Two Sigma，平台如 BlackRock Aladdin）**普遍具备、而本系统尚无**的能力。按"对基本面价值投资的边际价值"排序，逐项给出定位、要点、优先级。

### P4-1 多因子风险模型（Barra 式暴露分解）　⭐最高优先　影响★★★★★
- 把组合与个股的收益/波动**分解到风格因子**（价值/质量/成长/动量/规模/低波/杠杆）+ 行业 + 国家/市场 + 货币暴露；输出主动风险（tracking error）分解、因子拥挤度。
- **为什么关键**：现在 `portfolio_risk` 只有总波动/相关性，看不出"名义分散实则押同一因子"（伪分散）。因子模型是机构风险管理的骨架，也是判断"这份超额是 alpha 还是 beta"的前提。
- 交付：`tools/factor_model.py`（先用公开因子代理，如市值/账面市值比/动量/波动率构造，逐步接入更严谨的暴露估计）。

### P4-2 约束优化器升级（均值方差/风险平价/风险预算 + 全约束）　影响★★★★★
- 从当前 `portfolio_optimizer` 的逆波动，升级到：目标可选（最小方差/风险平价/风险预算/最大分散化）；约束涵盖行业/因子/单一/流动性/换手/现金；有效前沿；**交易成本感知**。
- **为什么关键**：真实调仓要在多重硬约束下求解，逆波动只是起点。

### P4-3 尾部与流动性风险 + 专用压力引擎　影响★★★★★
- VaR/CVaR（历史 + 参数 + 蒙特卡洛）；流动性风险（ADV、清算天数、冲击成本）；专用压力测试引擎（历史情景重放：2008/2015/2020/2022；假设情景：利率+X、汇率±Y、单一持仓归零；**反向压力测试**：多大冲击击穿风险预算）。
- **诚实**：VaR 只作补充，不替代回撤/流动性/集中度/尾部情景。

### P4-4 一致预期与盈利修正跟踪　⭐研究关键　影响★★★★☆
- 营收/EPS/目标价的**一致预期**、盈利修正动量、beat/miss 历史、分析师分歧度。
- **为什么关键**：价格常由"预期修正方向"驱动。现在系统能算 DCF、却看不到"市场预期在往哪边改、你的判断和 consensus 差多少"。
- 数据：先用免费源（Finnhub/FMP/Alpha Vantage 的 estimates，或财报电话会/研报抓取），标注覆盖率与时点。

### P4-5 三表联动财务预测模型（driver-based）　影响★★★★☆
- 收入驱动（量×价/分部）→ 利润表 → 资产负债表 → 现金流表**勾稽**，情景化，输出喂给 `dcf.py`。
- **为什么关键**：现在 DCF 只吃"假设"，没有前端建模，假设难以自洽（如高增长却不消耗营运资本）。三表模型让假设内部一致、可压力测试。

### P4-6 相对估值/可比公司引擎　影响★★★★☆
- comps：EV/EBITDA、P/E、P/S、PEG 横截面；历史估值分位；行业中位；由市价**反推隐含增长/回报**。
- 与 DCF 互为交叉验证（"绝对法 vs 相对法"）。

### P4-7 行业专用估值模型　影响★★★☆☆
- 银行（拨备/NIM/资本充足）、保险（EV/新业务价值）、地产（NAV/RNAV）、资源（储量/成本曲线）、SaaS（LTV/CAC/Rule of 40）、未盈利成长（单位经济/现金跑道）。
- 通用 DCF 套所有行业会失真；先做覆盖持仓最多的 2–3 个行业。

### P4-8 持股与内部人变动跟踪　影响★★★★☆
- 13F（美股机构持仓变动）、龙虎榜（A股席位）、大股东增减持、高管交易、股东户数变化、ETF/基金流向。
- **补 moneyflow 的诚实缺口**：主力资金流是逐笔估算，真实席位/内部人动向要看这些一手披露。

### P4-9 宏观 regime 引擎（工具级）　影响★★★☆☆（按策略）
- 增长/通胀/流动性/信用/利率/汇率/政策 的状态机；明确宏观判断**只影响哪些决策**（如现金区间、行业暴露），避免在自下而上研究里随意改估值假设。

### P4-10 资产配置（SAA/TAA）+ 跨资产　影响★★★☆☆（条件性）
- 战略/战术配置、目标区间、风险预算分配；跨资产（债/商品/REITs/加密）——各自建立 mandate 后再开发。

### P4-11 再平衡引擎　影响★★★☆☆
- 触发规则（阈值/日历）、税务感知、交易成本、批量调仓清单生成（现在 v6 调仓是手写脚本，应产品化）。

### P4-12 交易成本分析（TCA）+ 轻量订单管理　影响★★★☆☆
- 滑点/冲击成本、执行质量、订单状态机、预交易合规检查。真实资管才升 P0。

### P4-13 产业链图谱　影响★★★☆☆
- 客户-供应商网络、上下游景气传导、集中度暴露（单一客户/供应商风险）——补充定性尽调的结构化视角。

### P4-14 ESG 与可持续性　影响★★☆☆☆
- 治理/环境/社会评分、争议事件、监管风险（尤其 A/H 政策敏感行业）。

### P4-15 另类数据管线　影响★★★☆☆
- 招聘/App 下载/卫星/信用卡/舆情结构化接入（现仅 xueqiu），带授权/代表性/更新频率/失效风险标注。

### P4-16 情景与概率引擎　影响★★★☆☆
- 结构化情景树（牛熊基）、概率加权估值、蒙特卡洛、贝叶斯更新——把 decision_journal 的概率字段变成可计算引擎。

### P5（条件性）真实资管运营
- OMS/EMS、托管、清算、NAV、客户/监管报告——**仅当管理第三方资金时**升为 P0，并前置属地合规评估。

## 十、🆕 AI 系统特有治理（本系统的差异化控制线）

**这是一个 AI 驱动的投资系统——它有人类机构没有的失效面，必须专门治理。** 项目现有加固（联网预检、report_audit 准出、financial_rigor、"联网失败禁止伪装"、"客观/正反两面"原则、master-lens 异见庭）正是 AI 治理的雏形，应成体系升级到 L4（P3-8）。

| AI 特有风险 | 表现 | 治理动作 |
|---|---|---|
| **幻觉/编造** | LLM 编造数据、来源、财务数字 | 关键数据双源交叉（datalayer 已有）+ report_audit 准出 → 扩展到每份报告强制抽检、来源可点击可核 |
| **断网伪装** | 联网失败却用训练知识冒充实时结果（最危险失效） | WebSearch 预检 + "联网失败禁止伪装" → 升级为**硬门禁**：检测不到联网证据即拒绝出研究结论 |
| **过度依赖 LLM 判断** | 把"AI 说好公司"当结论 | 强制分离"AI 说了什么" vs "数据证明了什么"；大师镜片/评分只作思维工具，最终判断落到可核事实 |
| **prompt/skill 版本漂移** | skill 改一版，输出静默变化，无法复现历史结论 | skill 纳入模型登记（P3-2）+ 固定样本回归；报告标注 skill 版本 |
| **不可复现** | 同一问题两次跑结果不同 | 关键量化走确定性工具（financial_rigor/dcf/portfolio_risk），LLM 只做解释与判断 |
| **知识截止误用** | 用训练截止日旧事实当"最新" | 强制 `date` 校准 + 报告头标注数据截止日 → 纳入自动检查 |
| **谄媚/确认偏误** | 迎合用户预设立场 | "不预设立场/正反两面/反共识"原则 → master-lens 异见庭强制唱反调，并纳入决策日志 |

> **完成定义**：任何一份 AI 产出，都能回答"这段结论是联网核实的事实、还是模型推断？用的哪个 skill 版本、哪个数据快照？"——达不到就降级标注，不伪装确定性。

## 十一、🆕 投研运营节奏（机构的心跳）

## 十二、🆕 反模式清单（这类系统最常见的死法）

| 反模式 | 表现 | 对策 |
|---|---|---|
| **过拟合/数据窥探** | 回测调参调到漂亮，实盘失效 | 训练/验证/样本外分离；样本外+含成本验证（P3-6） |
| **虚假精确** | 把估计值报成小数点后两位的"精确" | 会失败原则：数据不足即停/降级；区分事实与估计 |
| **告警疲劳** | 告警太多→全部忽略 | 告警去重/优先级/静默期（P3-3） |
| **论文漂移** | 事实变了却悄悄改说辞不认错 | 决策日志不可回填（P1-1）；thesis-drift 检测措辞漂移 |
| **抱团/伪分散** | 名义分散实则押同一宏观/因子 | 组合相关性 + **因子暴露分解**（P4-1） |
| **叙事拟合** | 先有结论再找数据 | 客观原则 + 异见庭（master-lens）+ 空方论点强制 |
| **幸存者偏差** | 只看活下来的赢家 | 回测纳入退市/失败样本（P3-6） |
| **重买入轻卖出** | 有买入框架无退出纪律 | sell-discipline（P1-6） |
| **追资金/追技术** | 把叠加层当选股逻辑 | technicals/moneyflow 永不推翻基本面（P1-8 定位） |

## 十三、Definition of Done（每个 skill/工具的落地标准）

同时满足才算"机构能力已落地"：

- [ ] **范围明确**：解决/不解决什么、适用什么 mandate
- [ ] **输入明确**：字段/单位/币种/时点/来源/缺失值规则
- [ ] **输出明确**：结论/置信度/假设/限制/人工审批点
- [ ] **可复现**：同一数据快照+配置+版本→相同结果
- [ ] **可测试**：正常/边界/异常/历史 golden case 均有自动测试
- [ ] **防偏差**：point-in-time、幸存者、前视、成本、退市样本
- [ ] **可追溯**：结论→来源→转换→模型版本→决策人
- [ ] **会失败**：数据不足即停/降级，不制造精确幻觉
- [ ] **可监控**：成功率/耗时/数据新鲜度/异常/人工覆盖率
- [ ] **可复盘**：上线前定效果指标，上线后定期校准、淘汰无效规则

> 现状：多数已建工具满足"范围/输入/输出/可复现/可测试/会失败"（前 6 项 ≈ L3）；普遍缺"可追溯/可监控/可复盘"（后 3 项 = L4，由 P3 补齐）。

## 十六、最终判断（2026-07-13）

初版（07-10）的判断是"擅长确认一家好公司值不值得买，需要三次升级：报告→记录系统、能运行→可信赖、研究个股→管理闭环"。**这三次升级的工具层已基本落地**（账本/数据/风险/业绩/归因/估值/仓位/验伤/技术面/资金面，130 测试全绿，L3）。

**现在的准确定位与下一步：**

1. **底座工具已成形（L3），但还不是运转的机构（L4）。** 最高性价比的不是继续加工具，而是 **P3 制度化**——security master/点时财务库、模型登记与血缘、调度与告警、统一 watchlist、统一回测、错误模式库、AI 硬门禁。让已投入的能力真正可信赖、可复用、可审计。

2. **朝"顶级机构工具库"，仍缺若干核心能力域（P4）。** 按边际价值：**多因子风险模型（P4-1）> 约束优化器（P4-2）/尾部与流动性风险（P4-3）> 一致预期（P4-4）/三表模型（P4-5）/可比公司（P4-6）> 持股跟踪（P4-8）** 是首批要补的。它们是机构与散户工具的分水岭：能回答"这份超额是 alpha 还是 beta""风险到底压在哪个因子上""市场预期在往哪改"。

3. **顺序仍是：先制度化（P3），再补顶级能力（P4）。** 没有事实源持久化与统一回测，因子模型/尾部风险的输出也无法被信任和评价。

> **它现在擅长"确认一家好公司值不值得买"，并已能"记录、算风险、做业绩归因、加技术/资金面择时"。下一步要让它成为一台自己会跑、可审计的机器（P3），并具备顶级机构的因子风险、预期跟踪、约束优化能力（P4）——那才是一个可信赖、可进化、机构级的投研工具库。**
