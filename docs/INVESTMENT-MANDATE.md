# 投资授权与政策声明（IPS · Investment Policy Statement）

> 这是 AI Berkshire 投资决策系统的**总纲**。所有仓位、风险、卖出、再平衡建议都必须引用本文件（及其机器可读镜像 [`config/investment-policy.json`](../config/investment-policy.json)）里的**同一套约束**，skill/工具中不得再硬编码"前十大/现金比例"等阈值。
>
> **状态：草案 v0.1（2026-07-11）。下表带"待确认"的口径是为推进建设而设的默认值，需你确认后固化。**

---

## 一、投资授权（Mandate）

| 项目 | 口径 | 状态 |
|---|---|---|
| 投资风格 | 基本面驱动、长期、价值偏成长、**长仓为主**、集中持有 | 默认 |
| 投资范围 | A 股、港股、美股上市权益 | 默认 |
| 投资期限 | 3–5 年为主 | 默认 |
| 基准 | 按市场加权的**可投资总回报**基准（默认：沪深300 + 恒生 + 标普500 混合，权重随实际敞口） | 待确认 |
| 组合目标 | 长期复合回报最大化，同时**控制永久损失** | 默认 |
| 杠杆 | **不使用** | 默认 |
| 做空 | **不使用** | 默认 |
| 衍生品 | 仅限**备兑/保护性/建仓类期权**（如以目标价卖出 PUT 建仓）；不做投机性裸头寸 | 待确认 |
| 服务对象 | **自有资金**的投研与决策支持系统（非第三方资金） | 默认 |
| 最终决策 | AI 提供证据、情景与建议；**人类审批**后执行 | 默认 |

> 一旦开始管理第三方资金，本 IPS 的合规与运营条款（P3：OMS/托管/NAV/监管报告/属地合规）立即前置为 P0，不能仍按普通待办处理。

## 二、风险预算

| 项目 | 默认口径 | 说明 |
|---|---|---|
| 最大可接受回撤 | 组合层 **-35%** 为警戒线 | 超过须触发复审，不等于强制止损 |
| 现金区间 | **0%–30%** | 找不到好机会时，现金是合理仓位 |
| 单一标的永久损失 | 任一持仓的仓位不得使整个组合面临**永久出局**风险 | 塔勒布生存底线 |

## 三、仓位与集中度上限

> ⚠️ 本组合是**集中型价值投资**（当前单一标的可达约 47%）。以下上限按此风格设定，**刻意高于分散型基金**，请务必确认这是你的主动选择。

| 约束 | 默认上限 | 状态 |
|---|---|---|
| 单一标的 | ≤ **50%** | 待确认（当前最高约 47%） |
| 前三大合计 | ≤ **90%** | 待确认（当前约 89%） |
| 核心持仓数量 | ≤ **10** 只（卫星仓另计） | 默认（巴菲特式集中） |
| 单一行业 | ≤ **60%** | 待确认 |
| 单一国家/货币敞口 | ≤ **80%** | 待确认（当前中国敞口高） |
| Alpha 卫星策略（如新兴赢家）总仓 | ≤ **15%**，单标的 ≤ 3% | 待确认 |

## 四、流动性与可投资性

- 单一持仓建仓/退出不应显著冲击市价（默认：持仓 ≤ N 日日均成交额的合理倍数，具体阈值待定）。
- 港股需额外规避**老千股/仙股**（治理红旗一票否决）。

## 五、禁投清单（Exclusions）

- 看不懂商业模式的（能力圈外）。
- 有重大诚信/治理污点、疑似财务造假（Beneish/取证触发）。
- 需要杠杆或"下一个接盘者"才能获利的（博傻）。
- *（其余按你的价值观补充，如特定行业规避——待确认）*

## 六、复审节奏

| 周期 | 动作 |
|---|---|
| 每周 | 持仓健康度巡检、红线检查 |
| 每季 | 组合层复盘：业绩归因 + 决策校准 + 风险预算利用 |
| 每年 | **IPS 复审**：基准/风险预算/上限/禁投是否仍合理 |

## 七、审批与留痕

- AI 产出的每一条仓位/买卖/再平衡建议，须标注：引用的 IPS 版本、关键假设、是否越限、人工审批状态。
- 越过任一硬约束（集中度/流动性/禁投）时，必须显式标红并要求人工确认，不得静默执行。
