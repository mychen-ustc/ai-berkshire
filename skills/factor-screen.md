# 因子 IS-FDR 三态筛（OOS-first）

一次把 factor_library 的因子跑一遍 OOS 回测 + 多重检验门，输出三态裁决：$ARGUMENTS。信号与策略路线图 P2。

## 解决什么

单独跑一个因子看着"能赚"极易自欺——**没扣多重检验、没比对的基准、没做功效**。`factor_screen.py`（零依赖）把全部**可离线 PIT 重建**的因子一次跑完并施加门，关键是**三态裁决**：🟢通过 / 🔴拒 / **⚪不可判定**。

> ⚠️ 本工具 v1 曾犯错、经 5 位对抗性核验者查出并修正，见 `reports/因子筛复盘-诚实边界-20260717.md`。教训直接焊进设计：

| 门 | 判据 | 修正要点 |
|---|---|---|
| ①功效先行 | `power_at`<0.5 → **⚪不可判定**（不进 AND 淘汰）+ 给 MDE | **v1 错**:把"证据不足"当"因子无效"硬拒。低功效=不可判定≠negative |
| ②物质性 | OOS CAGR ≥ 门槛(默认 3%) | — |
| ③净超额 | 相对**同池等权(same-opportunity-set)** > 0 | **v1 错**:拿混合篮(含债/金)对比纯股 SPY，系统性冤枉低波/防御因子。SPY 仅并列 |
| ④显著性 | **相对同池等权的配对超额** block-bootstrap p | **v1 错**:检验 net_mean=0(赚钱>0)，牛市里同义反复。改测"跑赢同池等权" |
| ⑤家族 FDR | 配对超额 p 在因子家族内 BH-FDR(α)显著 | 分母=跑了几个因子 |

## PIT 边界（诚实,不静默跳过）

只筛能由本地源无前视重建的因子：`quality`(ROE, pit_financials.as_of)、`momentum`(12−1 价格动量, CSV as_of 截断)、`lowvol`(负波动, CSV)。**显式列"不可离线测"**：`size`(需历史流通股本, security_master 空/ETF 无股本)、`value`/`growth`(前瞻一致预期, 历史不可无前视重建)。

## 执行流程
```bash
python3 tools/factor_screen.py run --prices data/build_universe_prices_2y.csv --benchmark SPY --alpha 0.10
```
实测（14 标的 ETF+大盘股混合篮、每因子 OOS n=10）：**quality/momentum/lowvol 三面全部 ⚪不可判定**——功效 0.07–0.11、MDE 12–31%/年、配对超额 p 0.27–0.53 全不显著。**换用同池等权基准后 lowvol/momentum 的净超额由负翻正**（lowvol −5.27% vs SPY → +0.43% vs 同池；momentum −1.87% → +3.84%）——证明原"跑输"是资产配置漂移不是选股失败。

## 原则与诚实边界
- **不是"证伪也是成果"，是"这套数据谁都测不出来"**：每因子 OOS n=10，对 3%/年 的边际达 50% 功效需约 470 个 OOS 月(~39 年)。当前样本对因子有效性**任何方向都不能定论**。
- **基准决定 alpha 符号**：因子选出的组合相对"等权持有同一批标的"才叫选股技能；拿混合篮对比市值加权纯股 SPY 是苹果比橘子。同池等权是唯一诚实的无技能对照。
- **⚪不可判定 ≠ 🔴拒**：功效不足只说"证据不够"，绝不等于"因子无效"；两者用不同标签，禁止混为一谈。
- **混合篮非股票池**：14 标的含债/金 ETF，quality 实际只持 2 只票——本工具是**流水线压力测试**，非可交易因子研究。
- bootstrap 启发式(有效独立块≈n/3)，p 只看数量级不可给因子排序；coverage 无成分分母=unknown。**非交易建议。**
