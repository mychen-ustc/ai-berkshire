# 持仓优化报告（标准格式）

对 $ARGUMENTS 做机构级持仓优化，并按**固定结构 + 多样化图表**产出 md+html 报告。

## 这个 skill 解决什么

把"持仓优化"从随手分析升级为**可复现、全工具链、多视角**的标准流程。每次优化都在同一模板上迭代（v7→v8→v9…），保证：①用满全部工具能力与四大师哲学，②决策过程、结果、收益用多样化图表清晰展示，③诚实边界与治理闭环不缺席。

**铁律**：不要为"成长"堆同类 ETF（伪分散）；不要只看收益不看回撤；不要跳过任何一面。结论必须从数据推出。

---

## 第一步 · 全工具链分析（五面 + 估值 + 宏观 + 风险，缺一不可）

每次优化**必须**跑完以下模块，把输出喂进对应报告章节。只用其中几个 = 不合格。

| 维度 | 工具 | 产出 → 报告用途 |
|---|---|---|
| **候选盘点** | `watchlist.py list` / `radar.py` / `stock_screener.py` | 全候选池（持仓+观察+市场发现），不遗漏 |
| **实证画像** | `datalayer` + 自算年化收益/波动/最大回撤/效率 | 全域标的表 + 收益-回撤散点 |
| **消息面** | `news_engine.py` / `catalysts.py` | 催化剂、政策、事件 |
| **技术面** | `technicals.py` / `momentum_backtest.py` | 趋势/动量确认 |
| **基本面·估值** | `us_consensus.py`(美股) / `consensus.py`(A/港) / `comps.py` / `dcf.py` / `morningstar_fair_value.py` / `financial_rigor.py` | PEG/前瞻PE/EPS修正/公允价值 → 个股取舍依据 |
| **资金面** | `moneyflow.py` / `edgar_13f.py`(机构持仓印证) | 主力/13F → 多源印证 |
| **情绪面** | `sentiment.py market/stock` | 恐惧贪婪 → 追高/逆向警示 |
| **宏观** | `macro_regime.py now` | 美林时钟象限 → 成长/价值/防御倾斜的宏观依据 |
| **相关/伪分散** | `factor_model.py analyze` | 有效独立赌注数、PC1主导度 → 相关热力图 |
| **尾部** | `tail_risk.py analyze` | VaR/CVaR/压力/流动性 |
| **权重基准** | `portfolio_optimizer.py --method risk-parity/min-variance` | 纯低回撤锚（再据估值/宏观倾斜） |
| **定仓校验** | `position_sizing.py kelly` | 半凯利上限校验单只权重是否过重 |
| **调仓落地** | `rebalance.py` | 买卖股数/换汇缺口/成本/CSV |

**构建方法论**：以 `risk-parity` 权重为**低回撤锚**，再按 ①宏观regime ②个股估值(PEG/公允价值) ③情绪(贪婪则加压舱) ④13F/一致预期印证，做**有纪律的倾斜**，最后过 IPS 上限。给出 3-5 个版本构成**效率前沿**，让用户在成长↔防御间选刻度。

---

## 第二步 · 固定报告结构（md + html 双版）

命名：`reports/private/持仓优化-{版本}-{主题}-{YYYYMMDD}.{md,html}`（含真实持仓→private 私密）。

1. **执行摘要**：一句话结论 + 三组合对决表（反例/当前/推荐，含年化/波动/回撤/效率）
2. **决策流程图**：漏斗——候选池→五面筛选→估值→风险→构建→治理
3. **核心洞察**：本轮最重要的一个判断（如伪分散陷阱）
4. **全域实证画像**：所有候选的收益/波动/回撤/效率表 + 角色标注
5. **多视角交叉验证**：宏观regime + 情绪 + 13F + 一致预期 + 估值，五路印证结论
6. **构建逻辑（按功能分层）**：成长引擎/核心beta/防御压舱/特许经营/α分散器 + 各层解决什么
7. **效率前沿**：3-5 版本收益-回撤定位 + 推荐点
8. **相关性与真分散**：相关热力图 + 有效独立赌注数
9. **尾部风险验证**：VaR/CVaR/压力/单点冲击
10. **调仓订单**：v旧→v新 买卖股数/换汇/成本
11. **candidate watchlist 分档**：纳入/待研究/伪分散池
12. **诚实边界与反面论据**：回测≠未来、黑天鹅、税摩擦、单只双刃剑
13. **四大师视角**：巴菲特/芒格/段永平/李录各一句，点在关键决策上

---

## 第三步 · 图表词汇表（html 尽量多样化，≥6 种）

用纯 CSS/SVG 内联实现（零依赖、自包含）。每次至少用 6 种不同图表：

- **对决卡片**：反例/当前/推荐三张大数字卡（回撤为主数字，收益/效率为副）
- **决策漏斗**：候选N只 → 各步筛选 → 最终M只（逐级收窄的横条）
- **收益-回撤散点**：x=年化收益, y=回撤(越上越小越好)，气泡=各版本/各标的
- **效率前沿曲线**：SVG 折线，风险平价→防御→平衡→进取各点连成前沿
- **分层甜甜圈**：SVG donut，成长引擎/核心/压舱/特许/α各扇区
- **相关性热力图**：N×N 网格，蓝(低/负相关好)→红(高相关差)，标数值
- **因子暴露条**：PC1主导度对比（伪分散篮子 vs 本组合）
- **五面雷达**：SVG 蛛网，消息/技术/基本/资金/情绪五轴打分
- **宏观时钟**：四象限（复苏/过热/滞胀/衰退）高亮当前
- **情绪表盘**：0-100 恐惧贪婪半圆 gauge
- **估值对比条**：各标的 PEG/前瞻PE 横条，标便宜/贵
- **调仓瀑布**：v旧→v新各标的权重增减
- **13F印证**：本组合与伯克希尔重叠标的

**设计规范**：深色金融仪表盘底色；绿=好/正、红=差/负、金=引擎、蓝=防御；主题自适应；移动端单列；宽表 `overflow-x:auto`。

## 原则（最高优先级）

- **用满能力**：五面 + 估值 + 宏观 + 风险 + 治理，每次都跑全；只用几个工具是不合格的。
- **客观**：所有结论从数据推出，标注来源；呈现正反两面；不确定就说不确定。
- **风险平价打底、有纪律倾斜**：低回撤锚 + 估值/宏观/情绪倾斜，别拍脑袋定权重。
- **治理闭环**：报告出稿后 → `report_audit.py gate` 过硬门禁 → `error_library.py checklist` 事前验尸 → `decision_journal.py add` 登记决策（含 P(论点成立)）。
- **诚实边界必写**：回测窗口偏差、黑天鹅、税摩擦、regime 依赖。
