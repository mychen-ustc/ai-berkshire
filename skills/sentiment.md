# 情绪面分析：恐惧与贪婪的温度计

对 $ARGUMENTS 给出个股/市场情绪读数与舆情情感。

## 定位（最重要）

情绪是**反向指标的原料**：极度贪婪时多一分警惕，极度恐惧时留意机会（巴菲特"别人贪婪我恐惧"）。它是叠加层——辅助判断"情绪是否走到极端、你的认知与市场共识差多少"，**永不替代基本面与估值**。追情绪本身是投机。

## 三个口径
```bash
python3 tools/sentiment.py stock 600519          # 个股情绪（OHLCV 合成恐惧贪婪 0–100）
python3 tools/sentiment.py market --market US     # 市场情绪（大盘指数技术面 + VIX）
python3 tools/sentiment.py text "回购增持、业绩超预期，但面临诉讼"   # 舆情情感（中文金融词典）
```
- **个股情绪**：RSI + 距 52 周高 + 近 3 月动量 → 0–100 恐惧贪婪分（极度恐惧😱 / 恐惧 / 中性 / 贪婪 / 极度贪婪🤑）。
- **市场情绪**：大盘指数（A沪深300 / US SPY / HK盈富2800）的 RSI/位置/动量 + **VIX 风险计**（低=自满、高=恐慌）合成。
- **舆情情感**：内置中文金融情感词典（含否定翻转），对新闻标题/文本打分 −1..+1，可喂 `news_engine` 的标题流。

## 与其它工具的闭环
1. `/news-engine` 抓公告/新闻标题 → 2. `/sentiment text` 给每条打情感方向 → 3. `/sentiment market` 看大盘是否极端（择时上下文）→ 4. 结合 `/technical-analysis`、`/money-flow` 三个叠加层交叉印证。

## 原则
- **只在极端值参考**：恐惧贪婪分在中位（40–60）几乎无信息量；接近 0 或 100 才值得当反向信号看。
- **情绪噪声大、易反复**：不作为独立买卖理由；恐惧贪婪分是启发式合成、非市场共识的精确度量。
- **词典法情感不懂语境反讽**，只作粗筛；关键结论回到原文。
- A/H 无公开 VIX，市场情绪以指数技术面为主，缺一个独立风险计维度（诚实缺口）。
