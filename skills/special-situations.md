# 事件驱动/特殊机会：与大盘低相关的 alpha

对 $ARGUMENTS 分析特殊situation机会（并购套利/分拆/困境反转/私有化/指数调整/回购增持）。

## 这个 skill 解决什么
特殊机会是**与大盘低相关、确定性较高**的 alpha 来源，此前项目完全空白。`tools/special_situations.py` 提供并购套利计算；其余类型以框架为主。

## 类型框架

| 类型 | 机会来源 | 关键风险 | 分析要点 |
|------|---------|---------|---------|
| **并购套利** | 现价 < 收购对价的价差 | 交易告吹（监管/融资/股东投票） | 用工具算年化+期望值；破裂下行是生命线 |
| **分拆 spin-off** | 母子分拆后价值释放、被动抛售错杀子公司 | 子公司独立后基本面 | 关注被指数基金机械抛售的小市值子公司 |
| **困境反转** | 过度悲观定价、基本面拐点 | 价值陷阱、流动性/债务 | 区分"暂时受挫"与"永久受损"；现金流能否撑过 |
| **私有化/要约** | 要约价 vs 现价 | 要约失败、压价 | 大股东意图、少数股东保护 |
| **指数调入/调出** | 指数基金被动买卖的可预测冲击 | 已被抢跑 | 生效日前的资金流 |
| **回购/大股东增持** | 管理层用真金白银表态 | 只是姿态 | 回购是否**注销**、增持规模与价位 |

## 并购套利计算
```bash
python3 tools/special_situations.py merger-arb --current 95 --deal 100 --days 90 --downside 80 --prob 0.9
```
输出毛利差、年化(复利)、破裂下行、期望值、期望年化、**非对称赔率**（可接 `tools/position_sizing.py` 定仓）。

## 原则
- 套利收益的敌人是**交易告吹**——务必量化破裂下行与成交概率，别只看毛利差。
- 事件驱动仍须回答"最坏情况会不会永久出局"（塔勒布）。
- 数据须联网核验（deal terms/公告），禁止臆断。
