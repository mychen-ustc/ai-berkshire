# ETF 精选 — 投资 ETF 分析

本目录汇总对美股/全球 **ETF** 的投研分析。

## 分类速查（淘汰机制类型）

- **价值/质量纪律型**（契合价值投资，越贵越卖）：MOAT、COWZ、SCHD、QUAL、NOBL
- **动量型**（追涨、高换手，与价值投资相反）：MTUM、SPMO
- **宽基/成长指数型**：RSP（等权）、IWY（罗素前200成长）
